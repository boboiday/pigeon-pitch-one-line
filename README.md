Milo, a pigeon working St. Mark's Square, pitches investors his startup CooNet: a rooftop sensor network that warns the whole flock about hawks, one coo at a time. Problem, product, and a seed round of 2 million crumbs — in one line, 193 characters.

## Run it

```sh
node main.ts
```

This prints the pitch and writes it to `/output/entry.txt`.
